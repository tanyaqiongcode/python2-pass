# Py2 通关 🐍 · 上信考 Python 二三级特训（保二冲三）

**按三级合格→优秀标准设计的通关网站：上海市高等学校信息技术水平考试（SCITE）Python 程序设计及应用（二三级）。**

> 二三级是**同一张卷子、同一场考试**，按分数划档：不合格 / 二级合格 / 二级优秀 / 三级合格 / 三级优秀。所以正确策略是"按三级能力学习，保底二级"。本站的目标体系、题目难度、模拟考判分全部按此设计。

依据《上海市高等学校信息技术水平考试大纲（2025 年版）》制作，纯静态站点，无需安装任何东西：

- **难度递进学习流程**：14 题入学诊断定起点 → 六阶段路线图（语法筑基★ → 数据结构★★ → 函数与文件★★ → 库与工具★★ → 三级增量★★★🎓 → 综合冲刺），状态驱动的"下一步"引擎，每关题目按 ★基础/★★进阶/★★★挑战 分组
- **7 个关卡** 覆盖二级全部考点 + 三级增量（递归/正则/SQLite/数据可视化/OOP），每关 = 知识点速览（代码块可运行）+ 单选 + 程序填空 + 调试改错 + 编程题
- **浏览器内在线判题**（Pyodide 3.14 / CPython WASM）：支持 sqlite3、matplotlib、turtle（canvas 画布模拟）、GBK 编码；settrace 看门狗防死循环；无需本地装 Python
- **三种模拟考卷型**：标准卷（均衡抽题）/ 三级冲刺卷（三级重点题加权）/ **官方 A 卷 27A**（2026 官方模拟卷整卷还原，含 SQLite 数据库题与图形绘制题，判分标准同官方）
- **等第预估模型**：总分率 ≥60% 二级合格参考 / ≥75% 二级优秀参考 / 总分率≥75%且三级题≥60% 三级合格参考 / ≥90%且三级题≥80% 三级优秀参考；结果页给出分关卡得分与三级题得分率
- **题库全部经构建工具校验**：每道代码题的参考答案都在本地真实运行过、输出与期望逐字符一致（`tools/build_data.py`，CI 部署时再验一遍）

## 在线使用

开启 GitHub Pages 后直接访问：[Python 二级在线练习](https://tanyaqiongcode.github.io/python2-pass/)

本地使用：克隆后双击 `index.html` 即可（数据以 JS 文件加载，无跨域问题；判题引擎需联网首次加载约 10~20MB）。

## 快速开始（备考者视角）

1. 首页看倒计时和总进度，按 **7 周备考计划**（`#plan`）推进
2. 每关按 **速览 → 单选 → 填空 → 改错 → 编程** 顺序打，全绿即通关
3. 三级目标下第 7 关为**必修关**；第 3/5/6 周各来一场模拟考（推荐：标准卷 → 官方 A 卷 → 三级冲刺卷）
4. 考前：错题本清零 + 三级题得分率盯到 ≥80%

## 仓库结构

```
python2-pass/
├── index.html            # 单页应用入口
├── css/style.css         # 样式
├── js/
│   ├── config.js         # 全局配置（考试日期、判题 CDN、等第线）
│   ├── data.js           # 题库与课程（由 tools/build_data.py 生成，勿手改）
│   ├── app.js            # 路由、视图、模拟考控制器
│   ├── runner.js         # Pyodide 判题引擎 + turtle 画布模拟
│   ├── state.js          # 学习进度（localStorage）
│   └── util.js           # 工具（语法高亮/输出比对/markdown）
├── data_src/             # 题库源数据（JSON）+ 编写规范 SCHEMA.md
├── docs/official/        # 官方模拟卷 27A 原件（上海市教育考试院公开下载）
├── tools/
│   ├── build_data.py     # 题库校验 + 打包：运行参考答案验证期望输出，自动更新资源版本戳
│   ├── harness.py        # 本地判题 harness（与浏览器端行为一致）
│   └── turtle_stub.py    # 本地/CI turtle 桩（与浏览器画布 shim 状态数学一致）
└── .github/workflows/    # GitHub Pages 部署（部署前自动校验题库）
```

## 维护题库（贡献者视角）

```bash
# 1. 编辑 data_src/*.json（规范见 data_src/SCHEMA.md）
# 2. 校验并打包（会真实运行每道题的参考答案）
python3 tools/build_data.py
# 3. 提交后自动部署到 GitHub Pages
```

| 二、程序填空题 | 3 | 30 |

- 考试时间 150 分钟，满分 150 分；等第：不合格/二级合格/二级优秀/三级合格/三级优秀
- 环境：Windows 10 + Python 3.x（建议 3.8 / Anaconda3）
- 二级要求：数据类型、基本语句、模块化程序设计、常用算法、函数、文件与基于文本文件的数据分析；三级在此基础上加递归、数据库、数据可视化、正则（本站 L7）
- 官方渠道：https://scite.shmeea.edu.cn （大纲与模拟试卷下载）

## 技术说明

- 判题：[Pyodide](https://github.com/pyodide/pyodide) v314（CPython 3.14 WASM，多 CDN 回退），`input()` 提示文字单独捕获不污染输出比对，`settrace` 看门狗防死循环，turtle 用 canvas 模拟层承接（本地/CI 用等价 turtle 桩）
- 浏览器端已验证支持：sqlite3（含二进制 .db 以 base64 内嵌）、matplotlib（Agg + 自动放宽判题时限）、GBK 编码、openpyxl（micropip 自动安装）
- 已知限制：jieba/wordcloud/tkinter 无法在浏览器运行，相关考点以选择题/读代码理解呈现
- 兼容 localStorage 的现代浏览器；进度数据仅存本地
